# StreakFire — Habit Tracker

A single-page habit tracker built with React + TypeScript + Vite. Track daily habits, build streaks, and navigate weeks.

## Quick Start


npm install
npm run dev


Open [http://localhost:5173](http://localhost:5173) in your browser.

## Requirements
 
 Node.js 
 npm

## Features

 Add, rename (double-click), and delete habits
 Weekly grid with checkmark toggles
 Streak counter per habit
 Week navigation (prev/next/today)
 Data persists across page reloads (localStorage)
 Empty state when no habits exist
 Future days are disabled
